# User Stories för webbsidan "Läslistan"

### US1 - Visa startsida
Som användare vill jag komma till en startsida
så att jag kan navigera till funktioner som finns i min applikation

### US2 - Navigera mellan olika vyer
Som användare vill jag kunna navigera mellan katalog, lägga till bok,
mina böcker och statistik,  
så att jag kan använda olika vyer i applikationen.

### US3 - Visa katalog
Som användare vill jag kunna se en lista med alla tillgängliga böcker,  
så att jag kan få en överblick över alla böcker som finns.

### US4 - Lägga till bok
Som användare vill jag kunna lägga till en ny bok med titel och författare,  
så att jag kan utöka min läslista.

### US5 - Validering vid tillägg av bok
Som användare vill jag att formuläret kräver titel och författare,  
så att jag inte kan lägga till ogiltiga böcker.

### US6 - Markera bok som favorit
Som användare vill jag kunna markera en bok som favorit, 
så att jag enkelt kan hitta den senare.

### US7 - Ta bort favorit
Som användare vill jag kunna ta bort en bok från mina favoriter,  
så att listan hålls uppdaterad.

### US8 - Visa favoriter
Som användare vill jag kunna se mina favoritböcker,  
så att jag får en samlad vy över dem.

### US9 - Visa statistik
Som användare vill jag kunna se statistik över mina böcker,  
så att jag får en överblick över min läslista.

### US10 - Antal favoritböcker
Som användare vill jag kunna se antalet böcker jag har markerat som favoriter  
så att jag får en överblick över mina favoritval.
